# Contributing

Open an issue with the macOS, Node and PM2 versions, reproducible steps and expected behavior. Remove real paths, secrets, environment values and log payloads before posting examples.

For changes, install with npm ci, run npm run check and npm test, and keep changes focused. UI work should verify narrow screens and browser interactions. Preserve read-only monitoring and local-only access. Update docs when adding environment settings or changing collection scope.

Contributions are provided under the repository's MIT license. Runtime dependencies retain their own licenses.
